# Portfolio 5 – Implementation Evidence

This folder stores screenshots and supporting evidence from the Distributed and Cloud Database Exercise.

## Evidence Checklist

### Docker Deployment
- [ ] Docker Desktop running.
- [ ] PostgreSQL primary container running.
- [ ] PostgreSQL standby container running.

### PostgreSQL Replication
- [ ] Primary database configuration.
- [ ] Standby database configuration.
- [ ] Replication status verification.
- [ ] Successful student record replication.

### Sharding and Partitioning
- [ ] Partitioned examination results table.
- [ ] Partition query results.

### Availability and Consistency
- [ ] Replication lag or status evidence.
- [ ] Availability and recovery demonstration.

## Evidence Naming Convention

Use descriptive filenames, for example:

- `docker-containers-running.png`
- `postgres-primary-configuration.png`
- `postgres-standby-configuration.png`
- `replication-status.png`
- `student-record-replication.png`
- `partitioned-examination-results.png`
- `database-recovery-test.png`

## Note

Only verified implementation screenshots should be marked as completed evidence.
