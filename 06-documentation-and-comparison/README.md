# Distributed Database Documentation and Comparison

## Overview

This section documents the implementation results and compares distributed database design choices for the Student Management System.

## Areas of Comparison

### 1. Replication
How data is copied from a primary PostgreSQL server to a standby server.

### 2. Sharding
How student records can be distributed across multiple database servers.

### 3. Partitioning
How examination records can be divided into smaller sections.

### 4. Availability
How standby servers support database recovery and service continuity.

### 5. Consistency
How synchronous and asynchronous replication affect data consistency.

### 6. Cloud and Container Deployment
How Docker supports portable database deployment.
